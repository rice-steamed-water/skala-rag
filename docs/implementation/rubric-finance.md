> 근거: 원문 §3 "상세 평가 기준 — 실적 / 투자조건", [scoring §2–§4](scoring.md), 테스트 T21.

## 0. 공통 원칙

1. **rating은 1–5 정수 또는 null.** 0을 결측으로 쓰지 않는다. `null`은 missing_reason 필수([scoring §3](scoring.md)).
2. **관측(observed)의 조건:** 아래 criterion별 "최소 근거"를 모두 만족하고, 단위·기간·주체가 확인되며, 해소되지 않은 상충이 없다. 하나라도 빠지면 rating을 추측하지 않고 missing으로 둔다.
3. **미공개 ≠ 나쁨.** 재무가 공개되지 않은 것은 missing이다. 낮은 rating(1–2)에는 낮다는 **직접 근거**가 필요하다.
4. **참고 신호는 관측의 대체물이 아니다.** 원문의 SaaS 경험칙(매출총이익률 70–80% 등), 국민연금 인원 기반 인건비 역산, 기사 반복 노출은 rationale의 맥락으로만 쓴다. 이것만으로 rating을 주지 않는다.
5. **투자 단계는 자동 가점이 아니다.** Series C라는 이유만으로 Seed보다 높은 rating을 주지 않는다. 단계는 해석 맥락(limitations·rationale)에만 쓴다.
6. **같은 라운드만 조합한다.** 투자액·기업가치·지분율은 같은 라운드(같은 사건일·라운드 명칭)의 근거일 때만 함께 계산한다.
7. **임계값 비교는 반올림 전 값으로 한다.** Decimal 등 정확도 정책은 scoring §3과 같다. 구간은 `하한 이상, 상한 미만`이다.
8. **계산값은 derived Evidence다.** 계산·환산으로 만든 값은 `evidence_kind=derived`, `supporting_evidence_ids`, `derivation`(식·입력·가정)을 반드시 남긴다([contracts §3](contracts.md)). 추정 재무제표를 생성하지 않는다.

## 1. 재무 단위·기간 규칙 (T21)

### 1.1 기본 정의

| 값 | 정의 | 단위 | 비고 |
| --- | --- | --- | --- |
| 매출 | 손익계산서 매출액(영업수익) | 통화 원금액, 회계기간 | 같은 회계기준·연결/별도 구분 일치 |
| 매출총이익률 | (매출 − 매출원가) ÷ 매출 | % | 매출 ≤ 0이면 missing |
| 영업이익률 | 영업이익 ÷ 매출 | % | Rule of 40 입력 |
| 순현금소모(net burn) | 영업활동현금흐름이 음수일 때 그 절대값 | 통화/기간 | CAPEX 포함 여부는 `derivation`에 명시. baseline은 **영업활동현금흐름만** |
| 월 번레이트 | 순현금소모 ÷ 해당 기간 개월 수 | 통화/월 | 연간 자료를 12로 나눈 값은 "연평균 환산 월 번레이트" |
| 보유 현금 | 현금및현금성자산 + 단기금융상품 | 통화, 기준일 | 구성 항목을 derivation에 기록 |
| 런웨이 | 보유 현금 ÷ 월 번레이트 | 개월 | 아래 1.3 |

### 1.2 기간·통화 일치

- 성장률·이익률·Rule of 40은 **같은 정의의 두 기간**(원칙적으로 12개월 간격의 회계연도)만 비교한다. 연결/별도, 회계기준, 기간 길이가 다르면 missing(`period_mismatch`).
- 통화가 다르면 환산하지 않고 missing(`currency_mismatch`). 환산이 필요하면 환율·기준일을 derivation에 적은 derived Evidence로만 허용한다.
- 기사에 나온 "매출 ○○억"은 기간·연결 여부가 확인될 때만 매출 관측으로 쓴다. "연 매출 목표", "누적 수주", "계약 규모"는 매출이 아니다.

### 1.3 런웨이 단위 충돌 해소 (원문 L229)

원문은 정의를 `보유 현금 ÷ 월 번레이트`로, 데이터를 `현금 ÷ 연간 영업현금유출`로 적었다. 두 값은 12배 차이가 난다. 다음으로 통일한다.

1. **결과 단위는 항상 개월이다.**
2. 연간 영업현금유출만 있을 때:
   `월 번레이트 = |연간 영업활동현금흐름| ÷ 12`, `런웨이(개월) = 보유 현금 ÷ 월 번레이트 = 12 × 보유 현금 ÷ |연간 영업활동현금흐름|`
   - Evidence는 `derived`, derivation에 `annual_to_monthly_average` 가정을 적는다.
   - 이 값을 "현재 월 번레이트"의 직접 관측으로 표시하지 않는다.
3. 보유 현금의 기준일과 현금흐름 기간의 종료일이 다르면 missing(`period_mismatch`). 같은 재무제표(기말 현금 + 해당 연도 현금흐름)를 기본으로 한다.
4. **분모 0 이하 → missing.** 영업활동현금흐름이 0 이상이면 런웨이를 유한 개월로 만들지 않는다. `missing_reason=non_positive_burn`, `applicability_note=operating_cash_flow_non_negative`. 이 긍정 신호는 `traction.burn` rating에서 반영하고 런웨이에서 중복 가점하지 않는다.
5. **기준일 경과 보정:** `잔여 런웨이 = 런웨이 − (as_of − 현금 기준일)의 개월 수`. rating은 잔여 런웨이로 판단한다. 경과 개월 수와 계산식을 derivation에 남긴다.
6. **기준일 이후 조달:** 현금 기준일 이후 같은 회사의 투자 유치가 확인되면 `보유 현금 + 조달액`을 쓸 수 있다. 조달액·사건일·라운드가 확인된 경우에만, derivation에 합산 사실을 적는다. 조달이 확인되지 않으면 보정하지 않고 limitations에 적는다.
7. 직접 보고된 런웨이(예: IR 자료 "런웨이 20개월")는 기준일이 있을 때만 관측으로 쓰고, 5번의 경과 보정을 적용한다.

## 2. Traction rubric (영역 비중 10)

### traction.revenue_growth — 매출 성장률 (비중 3)

**최소 근거:** 같은 정의의 두 기간 매출(또는 기간이 명시된 직접 보고 성장률). **계산:** `(당기 − 전기) ÷ 전기`.
**missing:** 전기 매출 ≤ 0(`non_positive_base`, pre-revenue이면 `applicability_note=pre_revenue`), 기간·정의 불일치, 한 기간만 확인.

| rating | 제안 구간 (YoY) | 해석 |
| --- | --- | --- |
| 1 | < 0% | 매출 감소가 확인됨 |
| 2 | 0% ≤ g < 20% | 정체 |
| 3 | 20% ≤ g < 50% | 성장하나 뚜렷한 우위는 제한적 |
| 4 | 50% ≤ g < 100% | 빠른 성장 |
| 5 | g ≥ 100% | 연 2배 이상 |

경계 예시: 전기 50억 → 당기 75억 = 50.00% → **4**. 전기 50억 → 당기 74.99억 = 49.98% → **3**. 전기 0원 → 당기 10억 → **missing**(`non_positive_base`), rating 1이 아니다.

### traction.gross_margin — 매출총이익률 (비중 2)

**최소 근거:** 같은 기간의 매출과 매출원가, 또는 기간이 있는 직접 보고 값.
**missing:** 매출 ≤ 0, 매출원가 미공개, 기간 불일치. SaaS 70–80% 기준은 쓰지 않는다(하드웨어 포함 사업).

| rating | 제안 구간 | 해석 |
| --- | --- | --- |
| 1 | < 0% | 팔수록 원가 손실 |
| 2 | 0% ≤ m < 15% | 원가 부담 큼 |
| 3 | 15% ≤ m < 30% | 하드웨어 사업의 하단 |
| 4 | 30% ≤ m < 50% | 원문 하드웨어 참고범위 |
| 5 | m ≥ 50% | SW·서비스 비중이 높은 구조 |

경계 예시: 매출 100억, 매출원가 70억 → 30.00% → **4**. 매출원가 공개 없음 → **missing**, 기사 속 "고마진" 표현으로 대체하지 않는다.

### traction.burn — 번레이트 (비중 1)

원문 취지대로 절대값이 아니라 **추세와 매출 대비 관계**를 본다.
**최소 근거:** 두 기간의 영업활동현금흐름(과 성장 비교 시 같은 두 기간 매출). 한 기간만 있으면 그 기간 영업활동현금흐름이 0 이상일 때만 5로 관측, 그 외는 missing(`trend_unavailable`).
**missing:** 국민연금 인원 기반 인건비 역산만 있는 경우(참고 신호), 기간 불일치.

| rating | 기준 |
| --- | --- |
| 1 | 순현금소모가 증가했고 같은 기간 매출은 감소 |
| 2 | 순현금소모 증가율이 매출 성장률보다 큼 |
| 3 | 순현금소모가 증가했으나 증가율이 매출 성장률 이하 |
| 4 | 순현금소모가 전기 대비 감소 |
| 5 | 최근 기간 영업활동현금흐름 ≥ 0 (순현금소모 없음) |

경계 예시: 소모 40억→50억(+25%), 매출 +25% → 증가율이 성장률 **이하**이므로 **3**. 매출 +24.99% → **2**.

### traction.runway — 런웨이 (비중 2)

**최소 근거:** §1.3을 만족하는 보유 현금·월 번레이트(또는 기준일 있는 직접 보고 런웨이). rating은 **잔여 런웨이**로 판단.
**missing:** 분모 0 이하(`non_positive_burn`), 기준일·기간 불일치, 현금 기준일 미상.

| rating | 제안 구간 (잔여 개월) | 해석 |
| --- | --- | --- |
| 1 | r < 6 | 즉시 자금 조달 필요 |
| 2 | 6 ≤ r < 12 | 원문 "12개월 미만 위험 신호" |
| 3 | 12 ≤ r < 18 | 관리 가능하나 여유 제한 |
| 4 | 18 ≤ r < 24 | 원문 권장 하단 충족 |
| 5 | r ≥ 24 | 원문 권장 범위 이상 |

경계 예시(연간 자료): 기말 현금 90억, 연간 영업활동현금흐름 −60억 → 월 5억(연평균 환산) → 18.0개월. as_of가 기준일로부터 6개월 뒤면 잔여 12.0개월 → **3**. 영업활동현금흐름 +3억 → **missing**(`non_positive_burn`), burn에서 5.

### traction.concentration — 고객 집중도 (비중 1)

**최소 근거:** 상위 1개 고객의 매출 비중(감사보고서 주석의 주요 고객·특수관계자 매출, 공시, IR의 직접 수치).
**missing:** 기사에 고객사 1–2곳이 반복 등장한다는 정성 판단만 있는 경우(원문 방식은 참고 신호), 고객별 매출 비중 미공개.

| rating | 제안 구간 (상위 1개 고객 비중) |
| --- | --- |
| 1 | s ≥ 70% |
| 2 | 50% ≤ s < 70% |
| 3 | 30% ≤ s < 50% |
| 4 | 15% ≤ s < 30% |
| 5 | s < 15% |

원문 "한 고객이 절반 가까이면 리스크"는 2 구간의 근거다. 계열사·특수관계자 매출이면 limitations에 적는다.

### traction.rule_of_40 — Rule of 40 (비중 1)

**계산:** `매출 성장률(%) + 영업이익률(%)`, 두 값은 같은 당기 기준. **최소 근거:** revenue_growth가 관측 가능하고 같은 기간 영업이익이 있음.
**적용 조건:** 원문은 "주로 후기 단계"라고 했지만 단계로 자동 적용/제외하지 않는다. 입력이 없으면 missing(`inputs_unavailable`), pre-revenue면 `applicability_note=pre_revenue`. `not_applicable`로 비중을 제거하지 않는다([scoring §4](scoring.md)).

| rating | 제안 구간 (성장률 + 영업이익률) |
| --- | --- |
| 1 | x < 0 |
| 2 | 0 ≤ x < 20 |
| 3 | 20 ≤ x < 40 |
| 4 | 40 ≤ x < 60 |
| 5 | x ≥ 60 |

경계 예시: 성장 80% + 영업이익률 −40% = 40 → **4**. 성장 60% + 영업이익률 −20.01% = 39.99 → **3**.

## 3. Deal Terms rubric (영역 비중 10)

투자조건은 **투자자 관점에서 이 라운드에 들어갈 조건이 건전한가**를 본다. 단계가 높거나 기업가치가 크다는 것 자체는 가점이 아니다.

### deal_terms.stage — 투자 시리즈 (비중 2)

**최소 근거:** 라운드 명칭, 사건일(발표일과 구별), 실제 조달 완료 상태. TIPS 선정만으로 라운드를 확정하지 않는다([scoring §1](scoring.md)).
**평가 초점:** 라운드 진행의 건전성 — 후속 투자, 리드 투자자, 라운드 간격·규모의 정합성.
**missing:** 라운드 명칭만 있고 완료 여부·사건일 미상, 기사 간 라운드 명칭 상충 미해소.

| rating | 기준 (모두 근거 필요) |
| --- | --- |
| 1 | 다운라운드, 라운드 무산·철회, 기존 투자자 이탈이 확인됨 |
| 2 | 브릿지·익스텐션이 반복되거나, 직전 라운드 후 36개월 이상 후속 조달 없이 경과 |
| 3 | 라운드 완료는 확인되나 투자자·규모 정보가 제한적 |
| 4 | 라운드 완료와 리드 투자자(기관)가 확인됨 |
| 5 | 4에 더해 기존 투자자의 후속 투자(follow-on) 또는 전략적 투자자 참여가 확인됨 |

금지 예: "Series C이므로 5", "Seed이므로 1".

### deal_terms.valuation — Valuation (비중 5)

**최소 근거:** 금액·통화·날짜·pre/post 구분·해당 라운드([scoring §2](scoring.md)). `post = pre + 투자금`. pre/post가 표기되지 않은 "기업가치 ○○억 인정"은 missing(`pre_post_unknown`) — 아래 Q2 참고.
**평가 초점:** 가격의 적정성. 같은 snapshot 안의 근거(직전 라운드 기업가치, 실적 지표, 동종 비교 근거)로만 판단한다. 외부 상식의 "적정 배수"를 가져와 쓰지 않는다.

| rating | 기준 |
| --- | --- |
| 1 | 같은 snapshot의 동종 비교 근거(2건 이상) 대비 매출 배수가 현저히 높고 실적 근거가 없음 |
| 2 | 직전 라운드 대비 기업가치가 크게 올랐으나 그 사이 실적 개선 근거가 없음 |
| 3 | 가격을 과도하다고 볼 근거도, 정당화할 근거도 제한적 (이유 명시) |
| 4 | 직전 라운드 대비 상승이 실적 개선(매출·고객·양산) 근거로 설명되거나, 동종 비교 근거와 비슷한 수준 |
| 5 | 4의 두 조건을 모두 만족 (직전 대비 상승의 실적 근거 + 동종 비교 근거 대비 과도하지 않음) |

"크게"·"현저히"의 수치 기준은 Q3에서 정한다. 승인 전에는 rationale에 비교 배수를 숫자로 적는다.

### deal_terms.ownership — 지분율 (비중 3)

**계산:** `지분율 = 투자금 ÷ post-money` (같은 라운드). 또는 동일 거래의 지분율 직접 공개.
**평가 초점:** 해당 라운드의 희석 수준 — 창업팀 지배력과 후속 라운드 여력.
**missing:** 투자금과 기업가치의 라운드가 다름(`round_mismatch`), pre/post 미상, 투자금 미공개.

| rating | 제안 구간 (라운드 희석률 x) |
| --- | --- |
| 1 | x ≥ 40% |
| 2 | 30% ≤ x < 40%, 또는 x < 5% |
| 3 | 25% ≤ x < 30% |
| 4 | 20% ≤ x < 25%, 또는 5% ≤ x < 10% |
| 5 | 10% ≤ x < 20% |

경계 예시: 투자금 100억, post 500억 → 20.00% → **4**. post 500.1억 → 19.996% → **5**. 투자금은 Series B, 기업가치는 Series A 기사 → **missing**(`round_mismatch`).

## 5. 팀 결정이 필요한 질문 (D14 하위) — 작성자 의견 포함 논의용 초안

> **D05 승인(#3, 2026-09-30) 반영:** 적용조건 미확정은 `missing + applicability_note`, 비중 제거(not_applicable 재배분)는 미채택으로 확정됐다. §1–§3은 이미 이 기준을 따른다. 아래 Q4·Q6의 not_applicable 안은 v3(#35 / PR #36)가 D05를 대체하도록 승인될 때만 적용하는 **조건부 제안**이다.

아래 "작성자 의견"은 1차 제안(§1–§3) 이후 재검토한 내용이다. 합의 전에는 §1–§3과 `finance.yaml`을 바꾸지 않고, 합의된 항목만 같은 PR에서 반영한다.

| --- | --- | --- | --- |
| Q1 | 숫자 구간을 baseline으로 승인하는가 | §2·§3 표 | 대체로 유지. 단 ① **지분율 `x < 5% → 2` 삭제**, `x < 10%`는 4로 통합 — 후기 라운드의 작은 희석은 위험 신호가 아니며 이 구간이 가장 근거가 약함. ② **매출성장률 작은 기저 착시 보완** — 전기 매출이 작으면(예: 1억→5억 = 400%) 최대 4 또는 limitations 필수. 기저 기준액은 합의 필요. 런웨이(원문 기준)·매출총이익률(하드웨어 기준)은 유지 |

### 가장 큰 쟁점 — 데이터 가용성

구간보다 **데이터 확보 가능성**이 결과를 더 크게 좌우한다. DART 감사보고서는 외부감사 대상 기업에만 있어 Seed–Series A 상당수는 실적 10점이 통째로 missing일 가능성이 크다. 투자조건 일부까지 빠지면 **결측률 30% 보류** 규칙에 쉽게 걸려 추천 후보가 거의 나오지 않을 수 있다. 재무 파트에서 먼저 검토한 뒤 필요하면 팀 안건(D05 결측 분모·coverage)으로 올린다. fixture 단계에서 가상 후보의 결측률 분포를 먼저 확인하는 것을 제안한다.
